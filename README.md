# CetakPhoto Website

Final audited Next.js project for a no-scroll showcase that becomes a scrollable catalog when users choose Catalog.

## Run

```bash
npm install
npm run dev
```

Routes: `/` showcase, `/catalog` catalog.

## Before launch

Replace demo values in `content/catalog.ts`, use `.env.local` for `NEXT_PUBLIC_WHATSAPP_NUMBER`, add approved assets under `public/images/`, and complete the release blockers in `PROJECT-AUDIT.md`.
