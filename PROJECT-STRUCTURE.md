# Structure

- `app/page.tsx`: no-scroll showcase mode, rotating service/product stories
- `app/catalog/page.tsx`: scrollable catalog mode
- `components/`: shared header and catalog interaction
- `content/catalog.ts`: all products and services as typed data
- `content/media.ts`: future real photo map
- `lib/whatsapp.ts`: contextual inquiry links
- `app/globals.css`: tokens, hierarchy, responsive layout, motion, focus states
- `public/images/`: approved real photo assets
- `PROJECT-AUDIT.md`: design and release audit
